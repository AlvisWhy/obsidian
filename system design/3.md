What latency does the consumer act on
for > 1h , schedule batch
for 5=60 min, micro-batch spark structured streaming tirggered interval
for few seconds, true streaming
```python
events = spark.readStream
			.format('kafka')
			.option('subscribe','orders')
			.load()

query = events.writeStream
			.outputMode('append')
			.trigger(processTime='30 seconds')
			.format('delta')
			.option('checkpointLocation', '/chk/orders')
			.start()
```
