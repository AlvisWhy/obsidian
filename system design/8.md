Lakehouse:

parquet + delta/iceberg

acid/transactions can be guarantee via table format

The lakehouse add a transaction layer on the open cloud file

delta_log give ACID, time travel. MERGE over parquet files

For cost:
1 diagnose first, do not size up blindly
2 match compute to workload, short idle timeout
3 separate warehouses, multi-cluster for users, size up for one heavy query
4 separate compute per team

example
BI Dashboard Warehouse
交互式查询
- Size：从 Small 开始测试
    
- Min / Max Clusters：1 / 2
    
- Auto Stop：5–10 分钟作为起始值

大型分析 Warehouse
重查询
- Size：从 Medium 开始测试
    
- Min / Max Clusters：1 / 2
    
- Auto Stop：根据使用频率设置

这里把两种 workload 分开，是为了避免重查询挤占交互式 Dashboard 的计算容量。实际是否需要两个 Warehouse，要看工作负载冲突、使用成本和管理复杂度。
