CAP 分别代表：

- C — Consistency（一致性）：每次读取都能看到符合强一致性要求的最新成功写入。
    
- A — Availability（可用性）：每个到达正常运行节点的请求，都能得到非错误的响应（不保证一定读到最新数据）。
    
- P — Partition Tolerance（分区容错性）：即使网络分区导致节点之间无法通信，系统仍能继续运行

当网络分区（P）实际发生时，分布式系统必须在一致性（C）与可用性（A）之间作出取舍。

如果网络正常，没有发生分区，系统可以同时提供一致性和可用性。

**Quorum（法定人数 / 仲裁数）**是分布式系统中，为了保证数据一致性和容错能力，规定一次读或写操作必须获得的最少节点数量。

它常用于分布式数据库、复制系统和分布式存储。你可以把它理解为：不是所有节点都必须同意，而是必须有足够多的节点达成一致。

|概念|一句话理解|
|---|---|
|Quorum|操作需要满足的最小副本响应或确认要求|
|Majority Quorum|超过半数的节点|
|Read Quorum|读取需要的副本数|
|Write Quorum|写入需要的确认数|
|\(R+W>N\)|常用于确保读写集合相交的条件|
R: a read need R partition to reply
W: a write need W partition to commit
N: replication number
