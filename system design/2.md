这里的 `meta` 是 metadata（元数据） 的缩写，通常指存放 ETL 任务运行状态、增量水位、配置等信息的数据库或 schema。meta是自己建的一个表

```SQL
BEGIN;

-- 1. 写入目标表
INSERT INTO target.orders
SELECT *
FROM staging.orders;

-- 2. 更新增量水位
UPDATE meta.watermarks
SET last_value = :new_watermark
WHERE table_name = 'orders';

COMMIT;
```

For late arriving data
1 look back process
```SQL
-- idompotent
MERGE INTO marts.daily_revenus t
USING(
	SELECT order_date, SUM(amount) AS revenus
	FROM cureated_orders
	WHERE order_date > CURRENT_TIMESTAMP - INTERVAL '3 days'
	GROUP BY order_date
) s ON t.order_date = s.order_date
WHEN MATCHED THEN UPDATE SET t.revenue = s.revenue
WHEN NOT MATCHED THEN INSERT VALUES (s.order_date, s.revenue)
```
